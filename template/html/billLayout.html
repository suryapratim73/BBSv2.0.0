Sections

New templates start pre-built: Header (30%) / Body (40%) / Footer (30%) with the mandatory invoice fields inside. The Template dropdown in the workspace bar starts a Blank page, this pre-built Three Sections layout, or the Default 1 / Default 2 layouts instead. Fields can be removed or restyled; the three sections stay in this order. Select a section, then add blocks — they go inside it and inherit its font. Double-click any element to drill into it. Drag the red dots on a selected section's edges to resize it (top/left/right = the section's spacing, bottom = its height) and drag table column dividers to resize columns.
